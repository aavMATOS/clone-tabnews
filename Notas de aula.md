## Dia 5 Aula 5

### Comando git log --oneline
- Este comando mostra o log de commits do git de forma resumida mostrando o identificador e a mensagem do commit.

### Comando git diff
- Exibe as diferenças entre o arquivo commitado e o arquivo que está no "Working Directory".

### Comando git commit --amend
- Substitui o ultimo commit por um novo commit com suas alterações.

### Algumas observações:
- Existe uma convenção do unix que diz, que para identificar que um arquivo finalizou, se faz necessário a adição de um
caracter de "New Line" ao final do arquivo... hoje em dia, os sistemas modernos lidam bem com a ausência desse caracter
ao final do arquivo, mas é recomendado manter esse padrão.
